## 1. Введение

### 1.1. Наименование проекта: GenImg Pro

### 1.2. Цель проекта
Создание профессионального десктопного приложения для Windows, macOS и Linux, которое автоматизирует полный цикл производства графического контента для спортивных анонсов: от сбора данных и генерации изображений по шаблонам до перевода и подготовки к публикации в Telegram.

### 1.3. Ключевые изменения в v2.0 (по сравнению с v1.2):
- **Архитектура MVVM**: Внедрение четкой архитектурной модели (Model-View-ViewModel) для разделения логики данных, интерфейса и управления.
- **Централизованный кэш на SQLite**: Переход от файлового кэша к базе данных SQLite для более надежного и быстрого управления логотипами и метаданными.
- **Шаблонизация макетов**: Отказ от жестко запрограммированных макетов в пользу внешних конфигурационных файлов (JSON), что позволяет изменять дизайн постов без изменения кода.
- **Добавлена система отладочных сообщений**: Использование print() для отслеживания ключевых этапов работы приложения.

## 2. Финальная архитектура

- **Паттерн MVVM**: Четкое разделение View (GUI), ViewModel (логика и асинхронные задачи) и Model (работа с БД, API, генерация изображений).
- **База данных**: Используется двух-табличная схема (teams и team_aliases) на базе SQLite для гибкой работы с псевдонимами команд.
- **Асинхронность**: Все длительные операции (запросы к API, генерация изображений) выполняются через Worker + QThread, чтобы не блокировать GUI.
- **Обработка ошибок**: Централизованная обработка ошибок в ViewModel с отображением диалоговых окон пользователю.
- **Гибкая генерация изображений**: Использование Pillow и шаблонов JSON для макетов.
- **Конфигурация и секреты**: Все ключи и настройки вынесены в .env и config.py.

## 4. Требования к Модулям (актуализировано)

- **Core / Model**: Работа с кэшем (SQLite), API-клиенты, отладочные сообщения.
- **View**: Только отображение и сбор пользовательских действий (PySide6).
- **ViewModel**: Асинхронная логика, обработка ошибок, связь между View и Model.
- **Image Generator**: Генерация изображений по шаблонам.
