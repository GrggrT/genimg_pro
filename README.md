GenImg Pro v2.0
Краткое описание на 1-2 предложения.

Настольное приложение для быстрой генерации изображений для постов на спортивную тематику. Позволяет автоматически находить логотипы команд и создавать уникальные картинки на основе введённых данных.

Основные возможности (Features)
Здесь перечислите всё, чего мы достигли:

Графический пользовательский интерфейс (GUI) на PySide6.
Динамическая загрузка данных о командах через API-Football.
Локальное кэширование данных (названия, логотипы) в базе данных SQLite для минимизации запросов к API.
Асинхронное выполнение операций: приложение не зависает во время поиска в сети.
Генерация изображений на основе шаблонов с использованием библиотеки Pillow.
Интеллектуальная обработка ошибок и информирование пользователя через диалоговые окна.
Установка и запуск (Installation & Setup)
Это самый важный раздел для нового пользователя. Инструкция должна быть пошаговой.

Клонируйте репозиторий:

Bash

git clone [адрес_вашего_репозитория]
cd Genimg_pro
Создайте и активируйте виртуальное окружение (рекомендуется):

Bash

# Windows
python -m venv venv
venv\Scripts\activate
Установите все зависимости:

Bash

pip install -r requirements.txt
Настройте переменные окружения:

Создайте файл .env в корневой папке проекта (C:\Genimg_pro).
Откройте его и добавьте ваш API-ключ в следующем формате:
APIFOOTBALL_KEY="ваш_реальный_ключ_от_rapidapi"
Создайте базу данных:

Запустите скрипт для первоначальной настройки базы данных. Это нужно сделать только один раз.
Bash

python setup_database.py
Запустите приложение:

Bash

python main.py
